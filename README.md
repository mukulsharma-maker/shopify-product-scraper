# Shopify Product Name & SKU Scraper Web UI

## What it does
Paste Shopify collection or product links, then export:
- Product name
- Variant title
- SKU
- Price
- Availability
- Product URL

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

Example link:
```text
https://themissyco.in/collections/mosaique-spring-summer-2026
```

## Notes
This is intended for public Shopify pages. Respect website terms, robots.txt, and avoid heavy request volume.
